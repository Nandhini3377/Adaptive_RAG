Nimbus Labs Security Policy

This policy applies to every employee, contractor, and system at Nimbus Labs. Each rule has an ID such as SEC-101 so that audits and tickets can refer to it.

Policy summary

IDPolicyRule
SEC-101Password policyPasswords must be at least 14 characters and every account must use multi-factor authentication
SEC-102Data classificationAll data is labelled Public, Internal, Confidential, or Restricted

SEC-107Vendor reviewEvery new vendor that handles customer data needs a security review before signing

Policy details

SEC-101 (Password policy): Passwords must be at least 14 characters and every account must use multi-factor authentication.

SEC-102 (Data classification): All data is labelled Public, Internal, Confidential, or Restricted.

SEC-103 (Access reviews): Team leads review who has production access every quarter.

SEC-104 (Incident reporting): Suspected security incidents must be reported to #security within 1 hour.

SEC-105 (Data retention): Customer data is deleted within 30 days of account closure, and application logs are kept for 90 days.

SEC-106 (Encryption): Data is encrypted with AES-256 at rest and TLS 1.3 in transit.

SEC-107 (Vendor review): Every new vendor that handles customer data needs a security review before signing.

Error code details

Error AUTH-401 means the password is wrong; ask the user to reset their password.

Error AUTH-402 means the account is locked after 5 failed sign-in attempts; unlock it from the admin console after verifying identity.

Error AUTH-403 means the session token has expired; ask the user to sign in again.

Error AUTH-404 means the account does not exist; check the email address for typos.

Error AUTH-429 means too many requests from one IP address; wait 15 minutes before retrying.

Error PAY-402 means the card was declined by the bank; ask the customer to use another card.

Error PAY-409 means a duplicate payment was blocked; check the Ledger for the original transaction.

Error PAY-503 means the Ledger is unavailable; follow incident runbook INC-2041.
